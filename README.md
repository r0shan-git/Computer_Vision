# 🖥️ Computer Vision Project

## 📌 Overview

This repository contains multiple Computer Vision implementations using **OpenCV** and **Python**.
It covers fundamental to intermediate concepts like image processing, edge detection, and face detection.

---

## 🚀 Features

* 📷 Image Handling Basics
* 🔄 Image Resizing & Shaping
* 🎨 Image Drawing (Shapes, Text)
* 🌫️ Image Filtering & Blurring
* 🎥 Video Processing
* 🔍 Edge Detection & Thresholding
* 😊 Face, Eye & Smile Detection (Haarcascade)

---

## 🛠️ Tech Stack

* Python 🐍
* OpenCV
* NumPy

## ⚙️ Installation

### 1. Clone the repository

```
git clone https://github.com/r0shan-git/Computer_Vision.git
cd Computer_Vision
```

### 2. Create virtual environment (optional)

```
python -m venv cv_env
cv_env\Scripts\activate
```

### 3. Install dependencies

```
pip install -r requirements.txt
```

---

## ▶️ Usage

### Run Face Detection

```
python Face_Object_Detection/face_eye_smile.py
```
